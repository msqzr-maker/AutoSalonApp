# Информационная система автосалона

Данное десктопное приложение, разработанное с использованием C# и WPF, представляет собой информационную систему для автоматизации работы автосалона.
Система позволяет пользователям просматривать каталог автомобилей, а также оформлять продажи (заказы). Для пользователей с ролью «Менеджер» и «Администратор» предусмотрены функции просмотра, редактирования и удаления оформленных продаж. Взаимодействие с данными осуществляется через базу данных MS SQL Server.

## Установка

Для запуска проекта на компьютере необходимо выполнить следующие действия:

1. Установить Microsoft Visual Studio с поддержкой разработки WPF-приложений на C# (.NET 8 или выше).
2. Установить Microsoft SQL Server.
3. Развернуть базу данных, выполнив SQL-скрипт, расположенный в отчете к лабораторной работе (создание основной схемы и таблицы `[User]`).
4. Открыть файл решения `AutoSalonApp.sln` в Visual Studio.
5. Проверить строку подключения к базе данных в файле `Db.cs` (переменная `Cs`) и при необходимости изменить её в соответствии с настройками своего компьютера.
6. Восстановить необходимые пакеты NuGet (в частности, `Microsoft.Data.SqlClient`).
7. Запустить приложение клавишей F5.

Для корректной работы приложения необходимо, чтобы база данных была доступна по указанной строке подключения.

## Использование

1. **Авторизация.** При запуске приложения пользователь вводит логин и пароль для входа в систему.
2. **Регистрация.** Новый пользователь может создать учётную запись, указав необходимые данные. При регистрации ему назначается роль «User» (Пользователь).
3. **Каталог автомобилей.** После входа открывается главная страница с каталогом автомобилей. В таблице отображаются VIN, марка, модель, год выпуска, цвет, цена и статус.
4. **Оформление продажи.** Пользователь может оформить продажу, выбрав автомобиль, клиента, сотрудника и указав итоговую цену. Статус автомобиля автоматически меняется на «Продан».
5. **Управление продажами.** Пользователям с ролью «Manager» (Менеджер) и «Admin» (Администратор) доступен просмотр списка продаж, а также их редактирование (двойной клик по строке) и удаление. При удалении продажи статус автомобиля возвращается в «В наличии».
6. **Разграничение прав.** Обычные пользователи не могут просматривать и редактировать список продаж — соответствующие кнопки для них заблокированы.

## Структура проекта

- `AutoSalonApp/` — исходный код приложения.
  - `Entities.cs` — модель данных пользователя системы.
  - `Db.cs` — статический класс для работы с базой данных (выполнение запросов и транзакций).
  - `AuthService.cs` — логика авторизации и регистрации пользователей.
  - `LoginWindow.xaml` и `LoginWindow.xaml.cs` — окно авторизации.
  - `RegisterWindow.xaml` и `RegisterWindow.xaml.cs` — окно регистрации пользователей.
  - `MainWindow.xaml` и `MainWindow.xaml.cs` — главное окно: каталог автомобилей, список продаж и навигация.
  - `SaleEditWindow.xaml` и `SaleEditWindow.xaml.cs` — окно оформления, редактирования и удаления продажи.
  - `App.xaml` и `App.xaml.cs` — точка входа в приложение, запуск окна авторизации.
- `AutoSalonApp.sln` — файл решения Visual Studio.

## Данные

В проекте используется реляционная база данных Microsoft SQL Server. Для взаимодействия с ней применяется ADO.NET (библиотека `Microsoft.Data.SqlClient`).

Основные таблицы базы данных:

- **[User]** — пользователи системы, их логины, пароли и роли.
- **Supplier** — сведения о поставщиках.
- **Brand** — марки автомобилей.
- **CarModel** — модели автомобилей.
- **Car** — автомобили, их VIN, год выпуска, цена и статус.
- **Customer** — клиенты автосалона.
- **Employee** — сотрудники автосалона.
- **Sale** — оформленные продажи (заказы).

Полный перечень таблиц, их полей и связей определяется структурой базы данных, создаваемой SQL-скриптом (схема приведена к 3НФ).
